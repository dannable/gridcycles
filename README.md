# Gridcycles

A Tabletop Simulator mod: 2–4 riders race neon light cycles across an open table, leaving trails behind them. Crash into a trail and you respawn. Capture 3 Prizms to win.

An original reskin inspired by *Lazer Ryderz* (Greater Than Games). It isn't affiliated with or endorsed by them.

- Design and milestones: [PLAN.md](PLAN.md)
- Toolchain setup: [docs/SETUP.md](docs/SETUP.md)
- Working with Claude Code: [CLAUDE.md](CLAUDE.md)

Run the tests with `lua tests/run.lua`.
